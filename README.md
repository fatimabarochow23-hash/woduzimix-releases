# 我肚子混音

DaVinci Resolve 工作流整合工具：对白检索、补录对齐、总线配置、响度预混。

本仓库仅提供官方安装包、版本说明和自动更新信息。

## 下载

[下载最新版本](https://github.com/fatimabarochow23-hash/woduzimix-releases/releases/latest)

适用 Apple Silicon Mac、macOS 15.5 及以上、DaVinci Resolve Studio 21.1.0 Build 14。

保存工程并退出达芬奇，打开安装器，按提示安装。安装后从“工作区 → 流程整合 → 我肚子混音”打开。

## 检查更新

从 1.3.4 起，可在插件“设置 → 软件更新”中检查新版。点击“下载并更新”后自动下载、校验并打开安装器；保存并退出达芬奇后，按系统提示授权升级。个人设置、自定义预设和工程保留。

旧版没有更新入口，需要手动安装一次 1.3.4。无法连接 GitHub 时可稍后重试或手动下载。

安装包含音频分析工具和本地语音模型；YLA-3A、YLA-2A ex 效果器需单独安装。
